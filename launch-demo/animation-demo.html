Core Package デモ

高度UIアニメーション

基本と違う「目で見てわかる」動きの例です。スクロール＆ホバーでお確かめください。

① 左右からスライドイン＋スタッガー

基本は「上からだけ」。ここは左・中央・右から順番に登場します。

01 左からスライドイン
02 下から（0.4秒遅れ）
03 右からスライドイン

② カードの3Dチルト（ホバーで傾く）

基本はホバーなし。ここはマウスに追従してカードが傾きます。

A

カードに乗せて

ポインタの位置で傾きが変わります。

B

3Dっぽい動き

高度パッケージならこんな演出が可能。

C

目を引くUI

離すと元に戻ります。

③ テキスト＋下線が伸びる演出

基本はフェードのみ。ここは下線が左から右に描かれる演出です。

重要なメッセージは、
こうした演出で目を引けます。

④ パララックス（スクロールで奥が遅れて動く）

手前と奥の要素が違う速度で動く＝奥行き感が出ます。スクロールしてみてください。

奥
中間
手前

⑤ 数値が0からカウントアップ

基本にはありません。画面に入ると数字が0から増えていきます。

0 %
0 件
0 秒

※ サンプル・単位はイメージです

⑥ ボタンに光が流れる（ホバー）

基本は色が変わるだけ。ここはホバーで光の帯が流れます。
